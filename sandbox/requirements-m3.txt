# --- MCP server framework (C1) ---
# `mcp` is pinned below 2.0 on purpose. In mcp 2.x the bundled FastMCP was renamed to MCPServer
# (`mcp.server.mcpserver`), so the lesson's own import line — `from mcp.server.fastmcp import FastMCP` —
# dies at import time with "No module named 'mcp.server.fastmcp'". The course pins nothing, so a fresh
# build of the course image breaks the same way. Verified in this image: mcp 2.x installed =>
# CONNECTION_CLOSED when Claude Code starts the coursetools server.
mcp>=1.9,<2
fastmcp
